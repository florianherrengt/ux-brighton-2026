# UX Brighton media sourcing

Deliver accurate, usable, presentation-ready media without silently changing the deck.

## Establish the requested asset

Inspect the relevant narrative context in `draft.md` and `slides.md`, then search the repository and user-provided files before looking externally. If the user supplies an exact asset, preserve that choice. Resolve a factual mismatch through accurate naming, labels, and source status; ask before substituting a different subject.

When download is requested, save files in the appropriate `assets/` narrative folder. When the user asks only for options, present options without downloading unless they approve it. In either case, leave `slides.md` and `style.css` unchanged until integration is explicit.

## Select and verify media

Use the original source or an authoritative collection when possible. Record the original page, creator, and licence or rights status; never infer that an image is reusable merely because it is downloadable. Prefer watermark-free originals and verify the actual file type, dimensions, and visible content after download.

Before accepting an image, identify every subject or detail needed to communicate the claim. Reject crops that hide a person, machine, flag, interface, or other required evidence. Do not assume full bleed is desirable when the full frame carries meaning.

For profession photos, require a clearly visible face and unmistakable profession-specific work. “Designer” means product or UX design in this deck, not generic graphic, fashion, or industrial design. Reject backs of heads, tiny or obscured faces, generic office scenes, and watermarks.

Preserve originals when making generated or edited derivatives. Name derived files so their source pairing remains obvious, and record generated status accurately.

## Capture article headlines

For exact article-title screenshots or recaptures, read [references/headline-capture.md](references/headline-capture.md). Capture and inspect one requested file at a time.

## Handoff

Report the saved files, dimensions, source and rights status, and the visual criteria checked. State clearly that the deck was not changed when the request stopped at sourcing or selection.
