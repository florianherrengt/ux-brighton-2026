## Established content treatments

- The `meat-proxy-slide` uses the ink background, paper text, rust emphasis on “judgment” and “value,” and a 28px title-to-definition gap. Theme paragraph margins can override the intended spacing, so verify the computed gap.
- The red-flag slide retains both full, uncropped photographs because the flag bearer and machine jointly carry the meaning. It uses one shared bottom caption rather than separate panel labels.
