# Job market skills analysis — UX Brighton 2026

Analysis of what skills employers ask for in job postings, focused on UX/design roles
(also covers PM, frontend, backend, QA, platform/DevOps).

- `jobs-skill.md` — the full report ("Skills in demand, by role"), including the method
- `skill-counts.json` — granular UX Designer skill counts (n = 1,500)
- `ideal-jd.md` — the ideal job description used to probe the neighbourhood

Source: snapshot of ~2M live postings crawled **2026-09-09**. Generated with the
open-jobs tooling; the full project (crawler, dataset, tooling) lives at
`~/projects/open-jobs`. See the re-run section of that project for refreshed data.
